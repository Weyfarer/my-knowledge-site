# 知识库指南

这里是整个知识库的入口与使用约定。新朋友（未来的你）从这篇开始。

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-收件箱` | 快速记录，所有新笔记默认落在这里；定期清空归档 |
| `10-项目` | 进行中的项目、研发/技术文档（一个项目一个子目录） |
| `20-领域` | 长期主题知识（**主战场**），按领域建子目录，双链/标签组织 |
| `30-日常` | 每日笔记（`Ctrl+P` → 打开今日笔记） |
| `40-文献` | 摘录、剪藏、读书笔记 |
| `90-模板` | Obsidian 笔记模板（插入模板：`Ctrl+P` → 模板：插入模板） |
| `attachments` | 所有图片/附件统一存放，避免散落 |

## 工作流（Captur → Organize → Distill）

1. **捕获**：随手记 → 默认进 `00-收件箱`（`Ctrl+N`），或写进每日笔记 `30-日常`
2. **整理**：每周抽 15 分钟，把收件箱的笔记归类到 `20-领域`（按主题）或 `10-项目`（按项目），补上标签和双链
3. **沉淀**：用「通用笔记模板」把零散信息改成结构化笔记，链接到相关主题
4. **发布**：标记 `#publish` 标签的笔记会被 Quartz 站点收录（见 `../docs/` 部署文档）

## 命名规范

- 笔记名用「主题 + 必要限定词」，如 `Obsidian-插件架构.md`，避免无意义的 `未命名.md`
- 文件名不要包含 `/ \ : * ? " < > |` 等特殊字符
- 同一主题的系列笔记用 `名称-序号` 或子目录

## 双链习惯

- 笔记间尽量用 `[[双链]]` 连接，而不是复制粘贴
- 每篇成熟笔记末尾「相关笔记」至少挂 1 个链接（加入图谱）
- 想看知识连接：左侧栏「关系图谱」/ `Ctrl+P` → 图谱

## AI 使用

- **Smart Connections**：自动推荐相关笔记、语义搜索（设置里填 DeepSeek API Key 后可用云端嵌入）
- **Smart Composer**：对库内笔记问答、润色、生成（设置里填 API Key 后启用）
- API Key 获取：DeepSeek 开放平台 → 创建 API Key（费用极低）
